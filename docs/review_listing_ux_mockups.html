How this solves the screen

The seller sees only the important listing summary first. Everything else is either marked as captured, listed as pending, or moved into guided sheets. Publish stays blocked until required category data is complete.

  • Small readiness signal The 88% score is useful, but no longer dominates the page.
  • Pending is obvious The seller knows exactly what is blocking publish: condition details, accessories and pickup effort.
  • Condition is first-class Buyers see overall grade, working status, visible wear, defects and proof where relevant.
  • No data loss Captured groups show product identity, price, condition, category details, location, delivery, trust and handover.
  • Guided capture Each missing field opens as a short choice sheet, not a long form.
  • Final review After pending fields are done, the next step is buyer preview before publish.

Toys

Condition = cleanliness, parts complete, safety, age suitability, battery/working if powered, material, box/manual.

Books

Condition = pages complete, torn pages, markings, cover state, set completeness, language, class/board/edition.

Appliances

Condition = working status, visible wear, defects, accessories, capacity, power/install, pickup effort, bill/warranty.

Electronics

Condition = screen, body, battery, functional status, water damage, repairs, box/bill/charger, defects.
