# Design-system lint allow-list — Phase 3 final state (2026-05-02)
#
# Purpose: this file freezes the *known acceptable* residual drift so
# the lint catches NEW drift in NEW files without false-failing on
# known-good patterns. Every entry below has been audited; the
# remaining `<TouchableOpacity>` instances in these files are
# LEGITIMATE non-button-shaped patterns:
#
#   • Rich card rows — full-card tappable surfaces with image +
#     multi-line content + badge overlays (ListingCard, OwmeeListingCard,
#     MyListings, FeHome, FeOps card rows, etc.)
#   • Custom multi-line chip selectors — slot pickers with day-on-top-of-
#     time, condition cards with emoji+label+desc+radio (BookingScreen,
#     CreateListingScreen, Booking-style segmented selectors)
#   • Radio-row selectors in modals — Dispute reason, Return reason,
#     Sort options, NPS 0-10 score (TransactionDetail, Search)
#   • Backdrop tap-to-close — the modal-overlay pattern in bottom
#     sheets (PriceSheet, ComparablesSheet, EditDetailsSheet)
#   • Toggle rows — vertical-emoji-on-top-of-label selectors
#     (AddressDetails labelBtn, NPS scoreChip)
#
# These patterns intentionally don't fit the Button / IconButton /
# Chip primitives' semantic shapes. Forcing them through the
# primitives would add visual noise (e.g., a Button doesn't render
# multi-line content with a chevron suffix the way a card row does).
#
# To extend: if you genuinely add NEW drift to a file not on this
# list, the lint will fail and tell you. Either fix the drift OR
# add the file here with a justification line above the entry.
#
# Format: one path per line, relative to mobile/ root. Lines starting
# with # and blank lines are comments.
#
# This list was the burndown queue from the original 63-baseline.
# 27 files were fully cleaned and removed. The remaining 36 entries
# are the natural floor — Phase 3 is complete.
